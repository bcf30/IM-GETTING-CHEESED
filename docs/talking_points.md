# Talking points

Resume and interview narrative for the mozzavid-microstructure project. Each point pairs a
decision with the reasoning, so it holds up to follow-up questions.

## One-line summary

A reproducible Python pipeline that quantifies mozzarella microstructure from 591 synchrotron
X-ray CT volumes, running **every image operation inside headless Fiji/ImageJ** through PyImageJ,
and testing 25 cheese types with an assumption-checked statistical workflow.

## Fiji-only image chain

- Gaussian denoising, Otsu/Li thresholding, size-opening, 3D connected-component labelling and
  3D region measurement all run in Fiji (ImageJ Ops + MorphoLibJ), not in scikit-image.
- `mozzavid/fiji.py` is the single JVM gateway: it holds every version pin and every plugin,
  command and class string, and the numpy⇄Java conversion helpers. No other module imports
  `imagej`, `scyjava` or `xarray`. An AST test (`test_architecture.py`) enforces this layering.
- The JVM is a deliberate, documented exception to the otherwise stateless design: it can start
  only once per process and costs ~10–20 s, so `get_ij()` is a singleton that holds no per-volume
  state. Each per-volume Java object is created and disposed inside one function call.
- Why this matters in an interview: it shows I can integrate a heavyweight JVM tool into a clean
  Python architecture and keep the coupling isolated and testable.

## Sample as the statistical unit

- The dataset has ~4 volumes per physical cheese cube. Treating volumes as independent would be
  pseudo-replication. The pipeline pools objects per `sample_id` and uses the **sample** as the
  unit for all between-type tests.
- `stats.icc1` reports the one-way ICC(1) of volumes within samples for each metric, so the
  degree of within-sample correlation is quantified rather than assumed (hypothesis H10).

## Assumption-checked test selection

- `compare` runs **Levene's test** first. Equal variance → one-way ANOVA with η²; unequal
  variance → Kruskal–Wallis with ε². The post-hoc test matches the omnibus test: Tukey HSD after
  ANOVA, Dunn's test with Holm correction after Kruskal–Wallis.
- Tukey after Kruskal–Wallis was rejected (it assumes the very normality/equal-variance the
  omnibus test denied). Pairwise Mann–Whitney+Holm was rejected too: with n=6 vs 6 the smallest
  exact two-sided p (≈ 0.0022) exceeds the Holm threshold for the first of 300 pairs, so no pair
  could ever reach significance. Dunn's pooled-rank z-test has no such hard floor.
- Hand-computed reference tests pin η², ε², the Holm vector and a 3-group Dunn example with ties.

## Synthetic validation against ground truth

- `synthetic.generate` builds sphere-packing volumes with lognormal radii (pure numpy, no Fiji),
  heterogeneous (large, polydisperse) vs homogeneous (small, monodisperse).
- `synthetic.benchmark` runs the **same Fiji chain** on them and Welch-tests the two kinds. The
  test (`Property 13`) confirms the measurements separate the structures (both p < 0.01) and
  recover the ground-truth median diameter, all without needing the dataset.

## Falsifiable design hypotheses

- The design states each key decision as a hypothesis with the observation that would refute it
  (H1–H12 in `docs/reproducibility.md`), and the implementation records the outcome of each.
- Worked example from this build: the headless 3D max Feret feature (H7) is accurate but scales as
  O(points²) per object and **did not finish** on a real volume with ~1800 components (> 3 min vs
  < 1 s for all other features). The equivalent-ellipsoid proxy (already in the region table) is
  both faster and *more* accurate against analytic values (≤ 1.3% vs ~14% error on test spheres),
  so it replaced the direct feature. This is the Popperian loop in practice: a measured
  observation falsified the first choice, and the fallback was already specified.

## Reproducibility

- `environment.yml` pins every dependency, including Java 11 and Maven, on conda-forge.
- `docs/reproducibility.md` records the exact solved versions, the Fiji coordinate, the discovered
  MorphoLibJ command/class strings, the chosen backend, the sphericity mapping, and the outcome of
  every hypothesis. Discovery output is regenerated by `scripts/discover_fiji.py`.
- The pipeline writes byte-identical CSVs across runs (fixed float format, deterministic sort),
  checked by a determinism test.
